# 💪 Brijay Fitness – Responsive Gym Website

A modern and fully responsive gym landing page built using HTML, CSS, and JavaScript.

## 🚀 Live Demo
 https://brijaygits.github.io/gym-website/

---

## 📌 Features

- Responsive design (Desktop, Tablet, Mobile)
- Animated typing text effect using Typed.js
- Scroll animations using AOS (Animate On Scroll)
- Mobile navigation toggle menu
- Pricing plans section
- Testimonials section
- Smooth scrolling navigation
- Custom styled scrollbar
- Clean UI with modern design

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (ES6)
- Typed.js
- AOS Library
- Boxicons

---

## 📱 Responsive Design

- Fully responsive layout
- Mobile-first adjustments
- Optimized for small devices

---

## 🎯 Project Purpose

This project was built to strengthen frontend development skills and demonstrate:

- Layout structuring
- Responsive design implementation
- Interactive UI behavior
- Animation integration
- Clean Git workflow
